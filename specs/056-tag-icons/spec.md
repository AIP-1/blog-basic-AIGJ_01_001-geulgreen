# Feature Specification: 태그 화면 리뉴얼과 태그 아이콘

**Feature Branch**: `056-tag-icons` | **Created**: 2026-10-12 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-12 chan 시안 "태그창은 이런 느낌으로, 태그 앞 아이콘은 AI가 알아서 판단·아이콘 생성"). 끄는 설정 `blog.tag-icons.enabled`.

## User Scenarios & Testing
### User Story 1 - 태그 둘러보기 (P1)
`/tags`: 고양이 그림 배너, "인기 태그 · 전체 N개", 정렬(글 많은 순·많이 본 순·이름 순), 태그마다 아이콘·#이름·글 수·→ 알약(색은 주제마다). 홈 오른쪽 인기 태그도 같은 알약(작게).

## Requirements
- **FR-001** 아이콘 41개(선 그림)를 우리가 그려 둔다(`fragments/tag-icons.html`). 태그마다 아이콘·색 하나.
- **FR-002** 처음 화면에 나올 때 내장 규칙(낱말 → 아이콘)으로 바로 정해 저장한다. 맞는 규칙이 없으면 #.
- **FR-003** AI(021 연결: Gemini 키, 또는 설정으로 켠 Ollama)가 있으면 30분마다 규칙으로 정한 태그를 AI에게 다시 물어 목록 안의 아이콘으로 다듬는다. 보내는 것은 태그 이름(공개 정보)뿐. AI가 없으면 규칙 그대로.
- **FR-004** 많이 본 순 = 그 태그 공개 글들의 조회수 합. 모든 수는 공용 목록 조건(012).
