# Feature Specification: 보이는 대로 쓰기

**Feature Branch**: `060-visual-editor` | **Created**: 2026-10-12 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-12 chan 요청 "서식도구 누르면 바로 적용되는 걸 원해. 지금은 ** 이렇게 마크다운 형식으로 보여주는데 바꿔줘"). 글쓰기 본문을 노션·티스토리처럼 서식이 바로 보이는 칸에서 쓴다. 저장은 그대로 Markdown이라 004 자동 저장·005 발행·007 렌더링·008 사진·비교 창은 바뀌지 않는다.

## User Scenarios & Testing
### User Story 1 - 서식이 바로 보인다 (P1)
글쓰기 화면을 열면 본문이 글 화면과 같은 모양(제목·굵게·색·목록·할 일·인용·코드 블록·사진)으로 보인다. 글을 골라 서식 창(058)의 버튼을 누르면 `**` 같은 표시 없이 바로 굵게·색·제목 등으로 바뀐다. 되돌리기(Ctrl/⌘+Z)가 된다.

### User Story 2 - 노션식 단축 입력 (P2)
줄 처음에 `#`·`##`·`###`·`-`·`1.`·`>`·`[]`·```` ``` ```` 를 쓰고 띄어쓰면 제목·목록·번호 목록·인용·할 일·코드 블록이 된다. 코드 블록 안 Enter는 줄바꿈, 끝의 빈 줄에서 한 번 더 누르면 밖으로 나온다. 목록에서 Tab/Shift+Tab은 들여쓰기/내어쓰기.

### User Story 3 - Markdown으로 쓰기 (P3)
[Markdown으로 쓰기]를 누르면 예전 Markdown 칸(058 서식 창 그대로)으로 바뀌고, [보이는 대로 쓰기]로 돌아온다. 고른 쪽은 이 기기에 기억한다. JavaScript가 없으면 Markdown 칸만 보인다.

## Requirements
- **FR-001** 숨은 Markdown 칸(#post-content)이 저장의 기준이다. 보이는 칸에서 고치면 잠시 뒤(0.15초) Markdown으로 바꿔 넣고 입력 이벤트를 보내 자동 저장·미리보기가 따라온다. 칸을 떠나거나 탭을 닫기 전에도 바로 넣는다. 열기만 하고 고치지 않으면 Markdown을 건드리지 않는다.
- **FR-002** Markdown → 화면은 marked, 화면 → Markdown은 Turndown(+GFM)으로 하고, 두 라이브러리는 우리 서버의 /webjars/에서 내준다(CSP script-src 'self'). 제목은 글 화면처럼 한 단계 낮춰 보인다(## → h3).
- **FR-003** 화면에 넣는 HTML(그린 Markdown·붙여넣기·AI 결과)은 허용 목록으로 다시 거른다: 위험한 태그는 통째로 버리고, 모르는 태그는 벗기고, 속성은 링크 주소(http·https·mailto·상대), 우리 사진 주소, 코드 언어, 표 정렬, 할 일 칸만. 브라우저가 덧붙이는 글자 크기 같은 style도 지운다.
- **FR-004** 글자 색은 화면에서 지금 테마의 색(style)으로, Markdown에서는 058의 `md-c-`·`md-bg-` class로 옮긴다. 정해 둔 색이 아니면 버린다.
- **FR-005** 다른 곳에서 바뀐 Markdown(사진 대체글 채우기, 비교 창에서 고르기, 이 기기의 저장 안 된 내용 불러오기)은 화면에 다시 그린다. 사진 올리기는 커서 자리에 사진 문단(올리는 중 자리표시)을 넣고, 다 올라가면 바꾼다. 붙여넣거나 끌어 놓은 사진도 올린다.
- **FR-006** 붙여넣기: 다른 곳의 HTML은 거른 서식으로, 글자만 있으면 Markdown으로 읽어 서식을 살린다(코드 블록 안에서는 글자 그대로).
- **FR-007** 058 서식 창과 059 AI는 같은 버튼으로 보이는 칸을 다룬다(서식 종류·색·링크·AI 결과 바꾸기·아래에 넣기).

## Success Criteria
- 로컬 브라우저에서 확인: Markdown 9가지(제목·강조·목록·할 일·인용·코드·표·사진·색)가 화면 → Markdown → 화면으로 두 번 돌려도 같다, 단축 입력·코드 블록 Enter·서식 창 버튼·색·사진 자리표시·붙여넣기 거르기·되돌리기·모드 전환. EditorPageIT: 스크립트와 라이브러리가 실린다.
