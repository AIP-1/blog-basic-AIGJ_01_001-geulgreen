# Feature Specification: 글쓰기 서식 창

**Feature Branch**: `058-format-toolbar` | **Created**: 2026-10-12 | **Status**: Implemented (1.8.0 한 줄 도구 → 1.9.0 노션 모양 서식 창)

**Scope**: **강성찬 개인 확장** (10-12 chan 요청 "노션처럼 글 드래그 하면 간단하게 글 내용 바꿀 수 있는 거 띄우는 형식으로", 노션 선택 메뉴 화면을 참고로 보냄). 저장은 그대로 Markdown이라 004(자동 저장)·007(미리보기·렌더링 흐름)은 그대로다. 렌더러에는 밑줄·글자 색 태그 몇 개만 더한다(RENDER_VERSION 3). AI 칸은 059.

## User Scenarios & Testing
### User Story 1 - 고르고 서식 바꾸기 (P1)
본문에서 글을 고르면(드래그·두 번 누르기·Shift+화살표) 창이 뜬다. 넓은 화면은 본문 칸 오른쪽(노션처럼), 좁으면 고른 글 아래(자리가 없으면 위), 휴대폰은 늘 아래.
- 맨 위 **서식 종류**: 지금 종류(본문·제목·소제목·글머리 목록·번호 목록·할 일 목록·인용·코드 블록, 섞였으면 "여러 종류")가 보이고, 누르면 목록에서 바꾼다.
- **서식 칸**: 글자 색(A), 굵게, 기울임, 밑줄, 서식 지우기 / 링크, 취소선, 코드. 씌워진 서식은 눌린 모양이고 다시 누르면 벗겨진다.
- **색**: 글자 색 9가지 + 기본, 배경색 9가지(회색·갈색·주황·노랑·초록·파랑·보라·분홍·빨강). 다크 모드에서도 테마 색을 따른다.

### User Story 2 - 단축키 (P2)
Ctrl/⌘ + B 굵게, I 기울임, U 밑줄, K 링크, E 코드, Shift+X 취소선(한글 입력 상태에서도 같은 자리 키).

## Requirements
- **FR-001** 바꾼 글은 브라우저의 "글자 넣기"로 넣어 Ctrl/⌘+Z로 되돌릴 수 있고, 자동 저장·미리보기가 바로 따라온다(입력 이벤트).
- **FR-002** 글자 서식은 줄마다 따로 씌운다(문단·목록 항목을 넘지 못하므로). 줄 처음부터 고르면 제목·인용·목록 표시는 서식 밖에 둔다. 앞뒤 공백도 밖에 둔다. 따로 씌운 낱말이 섞인 문장 전체에 씌우면 안쪽 표시를 지우고 하나로 합친다.
- **FR-003** 밑줄은 `<u>…</u>`, 색은 `<span class="md-c-빨강 같은 이름">…</span>`(글자)·`md-bg-…`(배경)로 쓴다. 렌더러는 이 모양 그대로인 태그만 HTML로 살리고(속성·띄어쓰기가 하나라도 다르면 지금처럼 글자로 보임), 정화기는 `u`와 정해 둔 class의 `span`만 더 허용한다. 요약에는 글자만 들어간다.
- **FR-004** 색은 겹쳐 감싸지 않고 바꾼다. "기본"은 색을 지운다. 서식 지우기는 고른 글을 감싼 표시까지 넓혀 굵게·기울임·취소선·코드·밑줄·색·링크를 벗긴다(사진은 그대로).
- **FR-005** 서식 종류는 줄마다 앞 표시를 지우고 새 표시를 단다(번호 목록은 1부터). 코드 블록은 ``` 로 감싸고, 코드 블록에서 다른 종류를 고르면 울타리를 벗긴다.
- **FR-006** 링크: 주소만 적으면 되고 프로토콜이 없으면 https://. 공백·괄호는 바꿔 Markdown이 깨지지 않게 한다. 링크를 고르면 주소가 채워져 바꾸거나 [링크 빼기]. 사진은 링크로 보지 않는다. 위험한 주소는 공통 정화가 그대로 막는다.
- **FR-007** 창의 버튼을 눌러도 본문의 고른 글은 풀리지 않는다. Esc·다른 곳 누르기·글자 입력이면 닫힌다. 한글 조합 중에는 띄우지 않는다. 고른 글이 머리말 뒤로 스크롤되면 창도 가린다.

## Success Criteria
- 서식 규칙 자체 검사(`node src/test/js/format-toolbar.test.mjs`) 14개, 렌더러 문법·XSS 검사(밑줄·색 태그를 빌린 공격 4개 추가) 통과, 글쓰기 화면에 창 스크립트와 안내가 실린다(EditorPageIT).
