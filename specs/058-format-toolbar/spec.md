# Feature Specification: 글쓰기 서식 도구

**Feature Branch**: `058-format-toolbar` | **Created**: 2026-10-12 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-12 chan 요청 "노션처럼 글 드래그 하면 간단하게 글 내용 바꿀 수 있는 거 띄우는 형식으로"). 저장 형식은 그대로 Markdown이라 공통 007(렌더링·정화)·004(자동 저장)는 바뀌지 않는다. 화면 스크립트만 더하므로 끄는 설정은 두지 않는다.

## User Scenarios & Testing
### User Story 1 - 드래그하고 서식 고르기 (P1)
본문에서 글을 드래그(키보드로 고르기·두 번 누르기 포함)하면 고른 글 바로 위에 작은 도구가 뜬다. 굵게·기울임·취소선·코드·링크 | 제목·소제목·인용·글머리 목록·번호 목록·할 일 목록·코드 블록. 누르면 Markdown 표시가 씌워지고, 이미 씌워진 서식은 다시 누르면 벗겨진다(버튼이 눌린 모양으로 보인다).

### User Story 2 - 단축키 (P2)
고른 상태에서 Ctrl/⌘ + B 굵게, I 기울임, K 링크, E 코드, Shift+X 취소선. 한글 입력 상태에서도 같은 자리의 키로 동작한다.

## Requirements
- **FR-001** 바꾼 글은 브라우저의 "글자 넣기"로 넣어 Ctrl/⌘+Z로 되돌릴 수 있고, 자동 저장·미리보기가 바로 따라온다(입력 이벤트).
- **FR-002** 강조는 줄마다 따로 씌운다(문단·목록 항목을 넘지 못하므로). 줄 처음부터 고르면 제목·인용·목록 표시는 강조 밖에 둔다. 앞뒤 공백도 밖에 둔다.
- **FR-003** 따로 강조된 낱말이 섞인 문장 전체를 강조하면 안쪽 표시를 지우고 하나로 합친다.
- **FR-004** 제목·목록끼리는 서로 바뀐다(목록 → 제목, 번호 목록 → 글머리 목록). 번호 목록은 1부터 다시 번호를 매긴다.
- **FR-005** 링크: 주소 칸에 적으면 `[글](주소)`. 프로토콜이 없으면 https://를 붙이고, 공백·괄호는 바꿔 Markdown이 깨지지 않게 한다. 링크를 고르고 다시 누르면 링크를 뺀다(사진은 링크로 보지 않음). 위험한 주소는 공통 정화가 그대로 막는다.
- **FR-006** 도구는 본문 칸 안에 두고, 위에 자리가 없거나 터치 화면이면 아래에 둔다(휴대폰 기본 복사 메뉴를 가리지 않게). 좁은 화면에서는 두 줄로 접힌다.
- **FR-007** 도구 버튼을 눌러도 본문의 고른 글은 풀리지 않는다. Esc·다른 곳 누르기·글자 입력이면 도구가 닫힌다.

## Success Criteria
- 서식 규칙 자체 검사(`node src/test/js/format-toolbar.test.mjs`) 통과, 글쓰기 화면에 도구 스크립트와 안내가 실린다(EditorPageIT).
