# Feature Specification: 카드 대표 사진

**Feature Branch**: `055-card-cover` | **Created**: 2026-10-12 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-12 chan 요청 "카드도 그림 넣을 수 있게", 티스토리 "대표 이미지" 참고). 끄는 설정 `blog.cover.enabled`.

## User Scenarios & Testing
### User Story 1 - 카드 사진 고르기 (P1)
글쓰기 → 발행 설정의 "카드 대표 사진"에서 [자동(본문 첫 사진)] / 본문 사진 중 하나 / [새 사진 올리기]를 고른다. 고르면 바로 저장되고(발행과 따로), 목록 카드·검색 결과·공유 미리보기(OG)에 그 사진이 쓰인다.

## Requirements
- **FR-001** 대표 사진은 우리 저장소에 글쓴이가 올리기를 마친 글 사진만(남의 사진·외부 주소는 400, 남의 글은 404).
- **FR-002** 정하지 않으면 공통 규칙(005·008: 본문 첫 사진의 썸네일)이 그대로.
- **FR-003** 사진 정리 작업(008)은 대표 사진으로 쓰는 사진을 지우지 않는다(ImageReferenceLookup). 글이 지워지면 대표 사진 연결도 지워진다.
- **FR-004** 카드에는 썸네일, 공유 미리보기에는 원본.
