# Feature Specification: 글 고정

**Feature Branch**: `054-pin-post` | **Created**: 2026-10-12 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-12 chan 요청). 끄는 설정 있음.

## Requirements
- **FR-001** 글쓴이는 글 화면에서 [블로그 맨 위에 고정]. 블로그당 한 글, 다른 글을 고정하면 바뀐다. 블로그 첫 화면(필터 없음)에 "📌 고정 글"로, 공용 목록 조건(공개) 글일 때만 보인다.
