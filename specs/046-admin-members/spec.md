# Feature Specification: 회원 관리 강화

**Feature Branch**: `046-admin-members` | **Created**: 2026-10-12 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-12 chan 요청 "관리자 화면 추가"). 공통 022 신고·정지 화면 위에 더한다. 관리자가 아니면 404(42 P-10).

## Requirements
- **FR-001** 공통 회원 관리(022)에 이메일 검색, 이메일·가입일·발행 글 수 표시를 더한다. 정지·해제는 공통 그대로.
- **FR-002** 바꾸는 동작은 관리 기록에 남긴다(050).
