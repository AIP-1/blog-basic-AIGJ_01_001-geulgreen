# Feature Specification: 읽기 진행 막대

**Feature Branch**: `052-read-progress` | **Created**: 2026-10-12 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-12 chan 요청). 끄는 설정 있음.

## Requirements
- **FR-001** 글 화면 맨 위에 본문을 얼마나 읽었는지 스크롤에 맞춰 차는 막대(읽는 시간 표시는 chan 요청으로 넣지 않음). 스크립트가 없으면 막대도 없다. 설정 `blog.reading.progress-enabled`.
