블로그를 꾸미다 보면 제일 오래 고민하게 되는 게 색이에요. 글꼴이나 여백은 몇 번 바꿔 보면 금방 자리를 잡는데, 색은 하나를 바꾸면 다른 색이 전부 어색해 보이더라고요. 이번에 블로그 테마를 새로 정리하면서 색 팔레트를 처음부터 다시 만들어 봤어요. 그 과정에서 정한 기준과 시행착오를 공유해 볼게요.

![#1B4332부터 #F1FAEE까지 초록 여섯 단계가 나란히 놓인 글그린 팔레트 그림](image:18-1)

위 그림이 최종으로 고른 팔레트예요. 이름은 글그린 팔레트라고 붙였어요. 가장 진한 #1B4332부터 거의 흰색에 가까운 #F1FAEE까지, 초록 계열 여섯 단계로 이루어져 있어요. 한 가지 색을 중심으로 밝기만 바꿔 가니 어디에 써도 서로 잘 어울렸어요.

## 왜 한 가지 색에서 시작했는지

처음에는 마음에 드는 색을 여러 개 골라서 섞어 보려고 했어요. 그런데 버튼은 파랑, 태그는 보라, 링크는 주황 이런 식으로 정하다 보니 화면이 금방 산만해졌어요. 그래서 방향을 바꿨어요.

- 대표 색 하나를 먼저 정하기
- 그 색의 밝기를 단계별로 나눠서 배경, 테두리, 글자에 나눠 쓰기
- 강조가 꼭 필요한 곳에만 보조 색을 조금 쓰기

이렇게 하니 결정할 게 확 줄었어요. 새로운 요소를 만들 때도 여섯 단계 중에 하나를 고르기만 하면 되니까 고민이 짧아졌어요.

### 초록을 고른 이유

블로그 이름에 초록이 들어가기도 하고, 오래 글을 읽어도 눈이 덜 피로한 색이라고 느꼈어요. 진한 초록은 제목이나 버튼처럼 무게감이 필요한 곳에, 아주 연한 초록은 배경이나 카드 바탕에 쓰기 좋았어요.

## 단계별 역할 정하기

팔레트를 만들었으면 각 색이 어디에 쓰일지 정해 두는 게 중요해요. 저는 아래처럼 표로 정리해 두고 계속 참고하고 있어요.

| 단계 | 색상 코드 | 주로 쓰는 곳 |
| --- | --- | --- |
| 1 | #1B4332 | 제목, 진한 버튼 |
| 2 | #2D6A4F | 링크, 선택된 메뉴 |
| 3 | #40916C | 태그 테두리 |
| 4 | #74C69D | 강조 배경 |
| 5 | #B7E4C7 | 구분선, 비활성 상태 |
| 6 | #F1FAEE | 페이지 배경, 카드 바탕 |

이 표가 있으니 나중에 다른 사람이 테마를 손봐도 같은 기준으로 색을 고를 수 있어요. 혼자 쓰는 블로그라도 몇 달 뒤의 나는 다른 사람이나 마찬가지라서, 기록해 두길 잘했다고 생각해요.

### CSS 변수로 묶어 두기

정한 색은 CSS 변수로 한곳에 모아 두었어요. 그러면 나중에 색을 바꾸고 싶을 때 한 줄만 고치면 돼요.

```css
:root {
  --green-900: #1B4332;
  --green-700: #2D6A4F;
  --green-500: #40916C;
  --green-300: #74C69D;
  --green-200: #B7E4C7;
  --green-50: #F1FAEE;

  --color-bg: var(--green-50);
  --color-text: var(--green-900);
  --color-link: var(--green-700);
}

.button-primary {
  background: var(--green-900);
  color: var(--green-50);
}
```

색 이름은 숫자가 클수록 진하게 정했어요. 그리고 실제 컴포넌트에서는 색 이름 대신 역할 이름을 쓰도록 했어요. 이렇게 하면 다크 모드를 만들 때 역할 변수만 다른 값으로 바꿔 주면 돼요.

## 그라데이션으로 분위기 더하기

단색만 쓰다 보니 조금 심심하다는 느낌이 들었어요. 그래서 대표 이미지나 배너에 쓸 그라데이션도 몇 가지 만들어 봤어요.

![네 줄의 가로 그라데이션 띠와 각 띠의 시작, 끝 색상 코드가 적힌 그림](image:18-2)

이 그림에 있는 네 줄이 실험해 본 그라데이션이에요. 첫 줄은 #74C69D에서 #1B4332로 이어지는 초록 그라데이션이고, 두 번째 줄은 #FFD6A5에서 #FF9B85로 가는 따뜻한 살구색이에요. 세 번째 줄은 #A0C4FF에서 #6D6875로 차분하게 가라앉는 하늘색, 마지막 줄은 #FDFFB6에서 #CAFFBF로 이어지는 연한 노랑과 연두예요.

### 그라데이션을 고를 때의 기준

> 그라데이션은 양 끝 색의 밝기 차이가 너무 크면 가운데가 탁해 보여요.

여러 번 만들어 보면서 알게 된 점이에요. 그래서 저는 아래 기준을 지키려고 해요.

- 같은 계열 색끼리 이을 때는 밝기 차이를 크게 둬도 괜찮아요.
- 다른 계열 색을 이을 때는 밝기를 비슷하게 맞춰요.
- 글자가 올라가는 곳에는 대비가 충분한 쪽 끝에 글자를 배치해요.

결국 블로그 기본 배너는 첫 줄의 초록 그라데이션으로 정했어요. 나머지 세 가지는 계절 이벤트나 특별한 글에 가끔 쓰려고 아껴 두었어요.

## 실제 화면에 적용해 보기

색을 아무리 잘 골라도 실제 화면에 올려 봐야 진짜 느낌을 알 수 있어요. 그래서 글 목록에 나오는 카드를 먼저 만들어 봤어요.

![가을 산책, 색 고르기, 운동 기록이라는 제목의 초록 톤 글 카드 세 장 시안 그림](image:18-3)

이 그림은 글 카드 세 장을 나란히 놓은 시안이에요. 각각 가을 산책, 색 고르기, 운동 기록이라는 제목을 달아 봤어요. 카드 바탕은 가장 연한 초록, 제목은 가장 진한 초록, 태그는 중간 단계 초록 테두리로 처리했어요. 세 장을 같이 놓고 보니 통일감이 있으면서도 답답하지 않아서 만족스러웠어요.

### 적용하면서 고친 점

처음 시안에서는 카드 테두리를 진한 초록으로 했더니 너무 무거워 보였어요. 그래서 다섯 번째 단계 색으로 바꾸고 그림자를 아주 살짝 넣었더니 훨씬 가벼워졌어요. 또 제목 글자 색이 배경과 대비가 충분한지 확인하려고 명도 대비를 계산해 봤는데, 다행히 기준을 넉넉히 넘었어요.

## 마치며

색 팔레트를 만드는 건 결국 고르는 일보다 덜어 내는 일에 가까웠어요. 좋아 보이는 색을 다 쓰고 싶은 마음을 참고, 하나의 색을 여러 단계로 나눠 쓰는 쪽을 택하니 오히려 블로그에 개성이 생겼어요. 여러분도 테마 색을 고민하고 계신다면 대표 색 하나부터 정해 보세요. 나머지는 생각보다 자연스럽게 따라올 거예요.
