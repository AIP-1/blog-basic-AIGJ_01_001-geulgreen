오늘의 미션 주제가 "내 책상 위 풍경"이라는 걸 보고 한참 웃었어요. 마침 어제 책상을 정리했거든요. 평소 같았으면 종이와 컵이 뒤엉킨 모습을 보여 드려야 했을 텐데, 운이 좋았어요. 사진을 찍는 대신 위에서 내려다본 모습을 그림으로 그려 봤어요. 그림으로 그리니까 물건 하나하나가 왜 그 자리에 있는지 다시 생각해 보게 되더라고요.

![위에서 내려다본 책상, 노트북과 커피잔, 공책, 작은 화분, 빨간 펜](image:15-1)

## 위에서 내려다본 내 책상

그림 가운데에는 노트북이 있고, 오른쪽에 커피잔, 왼쪽에 펼친 공책과 빨간 펜이 놓여 있어요. 위쪽 구석에는 작은 화분이 하나 있고요. 물건이 많지 않은데도 하루 대부분을 이 다섯 가지와 함께 보내요.

### 물건마다 자리가 있어요

책상 위 물건의 자리는 오랫동안 바꿔 보다가 지금 위치로 정착했어요.

- 노트북은 정가운데에 둬요. 화면이 눈높이보다 조금 낮게 오도록 받침대 위에 올렸어요.
- 커피잔은 오른손 쪽에 둬요. 마우스를 쓰다가 자연스럽게 손을 뻗을 수 있는 거리예요.
- 공책은 왼쪽에 펼쳐 둬요. 생각나는 걸 바로 적으려면 덮어 두면 안 되더라고요.
- 빨간 펜은 공책 위에 올려 둬요. 다른 색 펜은 서랍에 넣고, 이것 하나만 꺼내 둬요.
- 화분은 손이 잘 닿지 않는 위쪽 구석이에요. 실수로 쏟을 일이 없어요.

이렇게 적어 보니 거의 모든 물건이 "손이 가는 순서"대로 놓여 있었어요. 따로 계획한 건 아닌데, 몇 년 동안 쓰면서 저절로 자리를 찾은 것 같아요.

### 빨간 펜 하나만 남긴 이유

예전에는 펜꽂이에 펜이 열 자루 넘게 꽂혀 있었어요. 그런데 정작 쓰는 건 늘 같은 펜이었어요. 그래서 하나만 남기고 나머지는 서랍에 넣었어요. 빨간색을 고른 건 공책에서 "이건 꼭 해야 해"라는 표시를 할 때 눈에 잘 띄기 때문이에요. 펜이 하나뿐이니 어디 갔는지 찾을 일도 줄었어요.

## 창가의 작은 화분

책상 위 물건 중에 제가 가장 아끼는 건 화분이에요. 일 년 전 친구가 이사 선물로 준 건데, 처음엔 손바닥만 했던 게 지금은 제법 커졌어요.

![창문 옆에 놓인 초록 잎 화분](image:15-2)

그림처럼 화분은 창문 바로 옆에 둬요. 햇빛을 좋아하는 식물이라 창가에서 멀어지면 잎이 금방 축 처지더라고요. 오후가 되면 창문으로 들어온 빛이 잎에 닿아서 초록색이 훨씬 밝게 보여요. 일하다가 눈이 피로할 때 이 잎을 잠깐 바라보면 마음이 조금 가라앉아요.

### 화분 돌보기 기록

처음에는 물을 너무 자주 줘서 뿌리가 상할 뻔했어요. 그 뒤로는 간단하게 기록하면서 돌보고 있어요.

| 할 일 | 주기 | 메모 |
| --- | --- | --- |
| 물 주기 | 일주일에 한 번 | 흙 겉면이 마르면 줘요 |
| 잎 닦기 | 이 주에 한 번 | 젖은 천으로 살살 |
| 화분 돌리기 | 사흘에 한 번 | 한쪽으로만 자라지 않게 |
| 영양제 | 한 달에 한 번 | 봄, 여름에만 |

"화분 돌리기"는 해 보기 전엔 몰랐던 일이에요. 식물이 빛 쪽으로만 자라서 한쪽으로 기울더라고요. 사흘마다 조금씩 돌려 주니 이제는 고르게 자라고 있어요.

> 식물은 말을 하지 않지만, 잎이 처지거나 색이 바래는 걸로 충분히 이야기해요. 매일 조금씩 보는 것만으로도 알아챌 수 있어요.

## 글그린 머그잔

책상 위 풍경에서 빠질 수 없는 게 머그잔이에요. 파란색 머그잔인데, 옆면에 "글그린"이라고 적혀 있어요. 이 블로그 이름이 적힌 잔이라 쓸 때마다 괜히 기분이 좋아요.

![김이 피어오르는 파란 머그잔, 옆면에 적힌 글그린](image:15-3)

그림에서는 잔 위로 김이 모락모락 올라오고 있어요. 아침에 처음 내린 커피를 담았을 때의 모습이에요. 저는 하루에 커피를 두 잔만 마시기로 정해 뒀는데, 첫 잔은 이 파란 머그에, 두 번째 잔은 오후에 작은 컵에 마셔요. 잔을 다르게 쓰니까 "벌써 두 번째구나" 하고 스스로 알아차리기 쉬워졌어요.

### 커피 루틴

- 아침 아홉 시에 첫 잔을 내려요.
- 글을 쓰거나 생각을 정리할 때 천천히 마셔요.
- 오후 두 시 이후에는 커피 대신 따뜻한 차를 마셔요.
- 잔은 다 마시면 바로 씻어서 책상에 얼룩이 남지 않게 해요.

마지막 습관이 은근히 중요해요. 빈 잔을 책상에 그대로 두면 하루가 지나면서 컵이 두세 개로 늘어나 있더라고요.

## 책상 정리를 오래 유지하는 방법

깨끗한 책상을 한 번 만드는 건 쉬운데, 그걸 유지하는 게 어려워요. 저는 하루를 마칠 때 작은 점검표를 마음속으로 한 번 훑어요. 개발자 친구가 이걸 보더니 "이거 그냥 체크 스크립트네" 하며 장난으로 코드로 바꿔 줬어요.

```javascript
const desk = ["노트북", "공책", "빨간 펜", "화분", "머그잔"];
const allowed = new Set(desk);

function checkDesk(itemsOnDesk) {
  const extra = itemsOnDesk.filter((item) => !allowed.has(item));
  if (extra.length === 0) {
    return "오늘도 깔끔해요";
  }
  return "치울 것: " + extra.join(", ");
}

console.log(checkDesk(["노트북", "머그잔", "영수증", "과자 봉지"]));
```

실제로 돌려 볼 일은 없지만, 원리는 정확해요. 정해 둔 다섯 가지 말고 다른 물건이 올라와 있으면 그날 치우는 거예요. 기준이 분명하니 "이건 둬도 되나?" 하고 고민할 시간이 줄었어요.

### 정리할 때 지키는 세 가지

- 책상 위에는 오늘 쓰는 물건만 둬요.
- 종이는 그날 안에 버리거나 파일에 넣어요.
- 퇴근할 때 노트북을 덮고 공책을 새 쪽으로 넘겨 둬요.

공책을 새 쪽으로 넘겨 두는 건 다음 날 아침을 위한 작은 선물 같은 거예요. 깨끗한 빈 쪽을 보면 하루를 새로 시작하는 기분이 들어요.

## 마치며

미션 덕분에 늘 보던 책상을 처음 보는 것처럼 바라봤어요. 노트북, 커피잔, 공책, 화분, 빨간 펜. 별것 아닌 물건들인데, 하나하나에 제 하루의 습관이 담겨 있었어요. 그림으로 그려 두니 나중에 책상이 또 어지러워졌을 때 "원래 이랬지" 하고 돌아올 기준이 생긴 것 같아요.

여러분의 책상 위에는 지금 무엇이 놓여 있나요? 이번 미션에 참여하신 다른 분들의 책상도 구경하러 가 봐야겠어요. 저마다 다른 풍경이 펼쳐져 있을 것 같아서 벌써 기대돼요.
